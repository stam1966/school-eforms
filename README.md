# School e-Forms

Πρόσθετο WordPress για ηλεκτρονικά έντυπα σχολείου (Δημοτικό, Γυμνάσιο, Λύκειο). Γονείς και εκπαιδευτικοί συμπληρώνουν τα έντυπα στον browser πάνω στα επίσημα υποδείγματα και παίρνουν PDF με πραγματικό κείμενο. Όπου χρειάζεται, το βεβαιώνουν στο gov.gr και το στέλνουν στο σχολείο.

- Τα στοιχεία των εντύπων μένουν στη συσκευή του χρήστη· η σελίδα δεν τα αποθηκεύει.
- Χωρίς εξωτερικά scripts ή CDN.
- Απαιτήσεις: WordPress 6.0+, PHP 7.4+.

## Εγκατάσταση

Κατεβάστε το `school-eforms-x.y.z.zip` από τις [Εκδόσεις (Releases)](https://github.com/stam1966/school-eforms/releases/latest) και στο WordPress: **Πρόσθετα → Προσθήκη → Μεταφόρτωση πρόσθετου**.

Οδηγίες, ρυθμίσεις και ιστορικό αλλαγών: [`README-el.txt`](README-el.txt) και `ANASKOPISI_*.txt`.
